# 만세력 앱 정답지 요청 — 남은 2건

신강약 산식은 **끝났습니다**(정답지 4건 4/4). 아래 2건은 남은 세 가지를 닫기 위한 것입니다.

## 넣을 사주 (둘 다 남자 / 양력)

| | 생년월일 | 시각 |
|---|---|---|
| **1** | **1965년 1월 14일** | **10:00** |
| **2** | **1967년 8월 14일** | **02:00** |

시각은 시(時) 경계 한가운데라 1~2분 틀려도 답이 안 바뀝니다.

## 캡처할 화면

**맹태주(1966-10-26) 보내주셨을 때와 똑같이** 쭉 내리면서 찍어주시면 됩니다. 제가 보는 건 셋입니다.

1. **신강/신약지수** — 득령·득지·득시·득세 ○✗ 와 단계 이름
2. **신살과 길성** — 기둥별 표 (천덕귀인·교록·정록 같은 게 어디 걸리는지)
3. **용신** — 대운수 바로 위

## 이 2장으로 닫히는 것

| 지금 상태 | 1번이 닫는 것 | 2번이 닫는 것 |
|---|---|---|
| 신살 5종 미구현<br>(천덕귀인·월덕귀인·태극귀인·교록·정록) | 일간 **무** / 월지 **축** | 일간 **경** / 월지 **신** |
| 괴강 표가 4일주인지 6일주인지 | 일주가 **무진** ← 여기서 갈립니다 | — |
| 극왕·태강의 억부용신 | **태강**(87.5%) 용신 | **신강**(75%) 용신 |
| 신강약 8단계 중 미확인 2칸 | **태강** 확인 | **신강** 확인 |

**1번의 일주 "무진"이 핵심입니다.** 우리 표는 괴강을 경진·경술·임진·임술 4개로 보는데,
앱은 맹태주 사주에서 **무술**을 괴강이라고 했습니다. 무진도 괴강이면 앱은 6일주 유파이고,
그러면 우리 표를 고쳐야 합니다.

## 이미 끝난 것 (참고)

신강약 = **비겁+인성 비율**. 여덟 글자 균등이라 12.5%씩 8개 값이 8단계와 1:1로 붙습니다.

| 비겁+인성 | 12.5 | 25 | **37.5** | **50** | **62.5** | 75 | 87.5 | **100** |
|---|---|---|---|---|---|---|---|---|
| 단계 | 극약 | 태약 | **신약** | **중화신약** | **중화신강** | 신강 | 태강 | **극왕** |

굵은 칸이 앱으로 직접 확인한 네 건입니다. 위 2건을 받으면 75·87.5도 굵어집니다.
