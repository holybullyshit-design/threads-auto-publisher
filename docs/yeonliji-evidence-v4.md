# 연리지 사주 근거 원고 v4 — 2026-08-30

## 적용 내용

- 29개 등록 주제 모두 같은 근거 기반 제작 경로 사용. 원고는 로컬 편집 카탈로그이며 무제한 GPT 자동 작성 기능이 아니다.
- 원국·일간·일지·오행·십성·합충·경진/무술일주·대운/세운의 구분·띠 궁합·날짜별 일진을 주제에 맞게 사용.
- 카드 3~4: 개념과 확인 가능한 규칙 예시. 카드 5: 해당 관계 질문에 적용. 근거ID와 출처를 manifest에 저장.
- 개인의 생년월일시를 입력받아 명식을 계산하는 기능은 이번 범위가 아니다. 개인 정보 없이 가짜 원국/대운/재회 확률을 만들지 않는다.
- 일진은 선택한 민간력 날짜의 정오를 기준으로 lunar-javascript 1.7.7에서 계산. 출생지·진태양시·자시 경계·개인 대운은 계산하지 않는다.
- 날짜형 시안을 다른 날짜에 예약하려 하면 차단하고 무료 재조판·재승인을 요구.
- 미확인 신살의 심리/이혼 해석은 추가하지 않았다. 귀문·화개 등은 별도의 검토된 해석 자료와 조건을 확보한 뒤 확장해야 한다.

## 근거와 한계

근거: [lunar-javascript 소스](https://github.com/6tail/lunar-javascript/blob/master/lunar.js), 로컬 설치 버전 1.7.7의 WU_XING_GAN, WU_XING_ZHI, SHI_SHEN, HE_GAN_5, HE_ZHI_6, CHONG, EightChar/Yun/DaYun.

규칙 계산을 검증하는 것이며 관계의 미래를 과학적으로 예측한다는 의미가 아니다. 같은 명리 개념이 여러 주제에 등장할 수 있다. 같은 개념의 다른 시안은 경고로 보여주되 의미적 중복을 완벽히 판정하는 기능은 아니다. 미사용 주제가 소진되면 반복 추천하지 않고 카탈로그 확장이 필요하다.

## 사용 순서 / 비용

1. Instagram 작업실 → 연리지 실타래.
2. 주제 선택 → 날짜 선택 → **7장 원고·명리 근거 먼저 보기 (무료)**.
3. 기존 시안은 **기존 그림으로 원고·한자 업데이트**. 아래 예약 날짜/시간을 사용하며 기존 파일을 덮어쓰지 않는다. 추가 이미지 API 호출 없음.
4. 새 장면은 **새 그림으로 7장 만들기 (API 유료)**에서 별도 비용 동의 필요. 일반 ChatGPT 로그인/무료 무제한 자동화로 바꾼 것이 아니다.
5. 7장 원본과 근거/캡션을 검수 → 명시적 승인 → 예약. 이번 작업에서는 게시·예약하지 않음.

## 검수 장치

- 미등록 주제·근거 누락·계산 불일치·원고 변경·해시 불일치·구버전 시안의 신규 예약 차단.
- 한자 포함 여부, 7장 구조, 원고 길이, 근거ID, 공개 내부표식, 강조 위치 검사.
- 이미지 규격과 파일 해시/완전 동일 이미지 검사. 닮은 포즈나 의미적 반복은 육안 검수 대상.
- 출처 원고와 실제 카드 3~4장 문구 일치 검사. 그림 생성 전에 검사하여 잘못된 원고로 유료 호출하지 않음.
- 수정 원고의 기존 그림 재사용은 장면-내용 적합성을 다시 확인해야 함. 파일 검사를 내용/그림 품질의 완전 보증으로 표시하지 않음.
- 캡션은 각 주제의 카드 내용·명리 개념·관련 태그로 작성. 내부 게시 식별자나 페이지 서명 미출력.
