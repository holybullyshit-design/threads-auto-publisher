## 사용하는 법

1. Instagram 작업실 → 연리지 실타래 → STEP 3에서 시안을 선택한다.
2. 위쪽의 예약 날짜와 예약 시간을 원하는 한국 시간으로 바꾼다. 오후 6시 고정이 아니다.
3. 7장과 캡션을 확인하고 승인 체크한다.
4. 선택한 날짜·시간에 예약하거나, 지금 바로 게시 버튼을 누른다. 즉시 게시에는 계정과 제목을 한 번 더 확인하는 창이 뜬다.
5. 아직 처리되지 않은 미래 예약은 같은 시안을 골라 시간을 바꾸고 다시 승인한다. 이미 게시된 시안과 결과 불확실한 시안은 재게시하지 않는다.

예약은 입력한 시각 그대로 저장하며 랜덤 시간 오차를 추가하지 않는다. 클라우드 실행 주기에 따른 실제 실행 지연은 가능하다. 실행까지 1분 이하인 예약, 이미 시간이 지난 예약, 게시 중/완료/실패 기록은 시간 변경을 차단한다. 날짜별 일진 콘텐츠는 다른 날짜로 옮기기 전에 무료 원고 업데이트와 재승인이 필요하다.
