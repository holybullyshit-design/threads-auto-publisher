# 3. 글 마지막 줄 공식 교체 (엔진 수정)

## 지금

```
정확한 건 원국을 봐야 나옵니다. 프로필에서 상담 신청하세요.
```
→ 무엇을 신청하는지, 얼마인지, 뭘 받는지가 없다. 150건/일이 전부 이 모양이다.

## 바꿀 구조 (3단)

```
[1] 무엇이 가르는지 구체적으로 지목   ← 지금 비어 있는 칸
[2] 그건 무엇을 봐야 아는지
[3] 상품 한 줄 + 링크                ← 지금 없는 칸
```

예 (팔자장인):
```
이 셋 중에서도 갈리는 건 띠가 아니라 태어난 날 일간이야.
일간이랑 대운을 같이 봐야 어느 쪽인지 나와.
100p 운명감정서로 정리해서 보내줄게. 프로필 링크 ▼
```

**[1]번 줄은 반드시 돌려 쓴다** — 한 문장으로 고정하면 10/30에 겪은 골격 과용이 그대로 재발한다.
`findOverusedTitleShape()`와 같은 방식으로 반복을 코드가 반려하게 만든다.

**수정 위치**: `server/skills/taebaekSajuDraftWriter.js` (closingLine / ctaInstruction),
`server/config/personaPresets.js` 계정별 `ctaInstruction`·`closingLine`.
